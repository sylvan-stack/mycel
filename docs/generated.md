# Historical summary evidence

The repository summary tree has been retired. Compatible stores can still hold
its generated dependencies, text, embeddings, evidence and activity. Current
read, search, status, detection and embedding paths exclude its nodes. The
existing repository removal command still removes all indexed state for the
selected repository.

Use [quiet-period maintenance](summaries.md) for ordinary document ingestion and
embedding. The overview command continues to project its own index sections.
